# comp-theory-assessment-submission
My submission for computational theory module assessments

## Setup
Clone the repository, install the Python dependencies, and launch the notebook:

```powershell
git clone <repo-url>
cd comp-theory-assessment-submission
python -m venv venv
# for windows
.\venv\Scripts\activate

# linux
source ./venv/bin/activate

python -m pip install -r requirements.txt
jupyter notebook problems.ipynb
```
